
## 1: When does the function body run?

- Function body run when we call function

- for example:
 
    ``` python
        
        def welcome_message():
        message = "Welcome to LearnForge"
        return message

        result = welcome_message()
        
    ```

- At line 13 we call function welcome_message() and store returned value in result variable. 

- When we call function welcome_message() then function execute or run

- return keyword only return value and not print anything on screen or teminal

## 2. Why does return not display the text itself?

- return send value back to the code that called the function

- print() is used to dislpay something on screem or terminal

- ex.1 

     ``` python

        message = "Welcome to LearnForge"
        return message
    ```
