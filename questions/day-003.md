
## Why does assigning b = a not always give an independent copy?

- assigning b = a not always give an independent copy beacuse both object pointing to same object in memory.

- If you change in any of one, it will reflect in both

- ex.

    ``` python
        a = [1,2,3,4,5]

        b= a

        a.append(6)
        print(f"b: {b}")
        print(f"a: {a}")
    ```

- If you want independant copy then you can use copy() on it

- ex

    ``` python
        a = [1,2,3,4,5]

        b= a.copy()

        a.append(6)
        print(f"b: {b}")
        print(f"a: {a}")
    ```
