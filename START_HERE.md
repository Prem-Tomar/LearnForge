# Start here — six learners

## Day 001 setup

Choose Learner 01–06 slots and a shared review time. The course has 182 personal days each: five 3-hour and two 4-hour sessions per week, including learning, coding, group architecture, review, integration, and breaks. Start dates are relative.

Check that each person can save a text file, open a folder, and open a terminal. A terminal is where you ask a program to run; it differs from a Python prompt. Explain this before expecting a programming vocabulary. Use a supported CPython 3.13 or later runtime and record the exact version.

From the repository folder run:

```text
python --version
python run_demo.py
```

On Windows, `py -3.13 run_demo.py` also works when that version is installed. The starter requires no external packages, network, API key, or GPU. It names LearnForge, honestly reports the starter stage, and shows the welcome capability. It does not claim future AI/ML features already exist.

Record personal evidence through the current single owner of the shared ledger.

## Gradual AI/ML destination

Weeks 1–6 teach Python deeply; APIs, data/mathematics, model workflows, deployment, and debugging follow gradually. Everyone completes the common foundation. At the week-20 gate each chooses an [AI/ML specialization](SPECIALIZATIONS.md), then builds a complete small real capability in weeks 21–26. No topic is assigned without that learner's choice.

Add virtual environments, package installation, databases, containers, model SDKs, and frameworks when their lessons introduce them. Ordinary work uses synthetic data and fake/local paths. Record dependency versions at phase boundaries. Keep testing light and attached to a feature. Do not add API documentation unless requested.

## If a day overruns

Use the review/repair block. Cut optional polish, repeated reading, extra abstractions, and excessive test work first. Preserve the concept, personal proof, shared architecture, review, working feature, and important permission/data/effect checks. If a prerequisite still fails, record extra time and move dependent work; do not silently remove concepts or award a calendar-based pass.
