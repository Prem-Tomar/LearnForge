## Why the files are separate

Value functions have predictable inputs/results and no network dependence. Parsing and requests deal with unreliable external data. The search coordinator owns which request may update the result. Wiring composes them without turning every function into a network client. Later, a selected learner moves only a reviewed useful unit into their owned web/mobile feature; copying exercise files into a shared package is not automatic.

For each pure function, name the input/output and prove whether the input changes. For each adapter, name the outside dependency, failure types, cancellation behavior, and cleanup owner. Learn the words by tracing concrete examples before using them in an interview answer.

## Exit check

Without a teammate's implementation, each person validates a record, makes an immutable update, explains a closure and promise ordering, prevents an old search overwriting a new search, and cleans up a subscription. Ask one question from each completed session with a new value or timing. A guessed output without a causal explanation needs another example. Use [the separate coach key](../../coach/javascript-interview-key.md) after the initial attempt. Keep difficult items warm at +1, +3, and +7 later sessions and during the feature reviews.
